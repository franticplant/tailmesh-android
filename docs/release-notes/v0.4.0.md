Tailmesh 0.4.0 moves to Tailscale 1.105, fixes IPv6 sites breaking over WireGuard upstreams, and adds remote control: you can now manage and debug the app from your computer.

Installs as an update over 0.3.x, keeping your tailnets and settings. Most phones want the `arm64-v8a` APK; use `universal` if unsure.

## New: remote control and debugging

An opt-in API (**Settings → Remote control & debugging**) that can do everything the app's screens can: tailnets, upstreams, per-app routing, listeners, DNS and diagnostics settings, packet captures (with download), live logs and Go profiling. `tailmesh-ctl`, attached for Linux, macOS and Windows, is the command-line client.

- **Sign-in:** approve each connection on the phone (Allow / Read-only / Deny, with a matching code), use a password, or both. One shared rate limit covers all sign-in attempts.
- **Read-only by default:** a session can only change things if you grant it control and "Allow changes" is on. Turning that off makes every session read-only at once.
- **Logged:** every request and sign-in attempt goes to an append-only access log. Nothing reachable remotely can change remote control's own settings, sessions or log.

See [docs/features/04-remote-control.md](https://github.com/franticplant/tailmesh-android/blob/v0.4.0/docs/features/04-remote-control.md).

## Fixes

- **IPv6 sites failing with `ERR_CONNECTION_CLOSED`.** A WireGuard upstream with only an IPv4 tunnel address used to accept IPv6 connections and then drop them, so browsers never fell back to IPv4. Upstreams now refuse address families they can't carry before accepting, and DNS stops returning IPv6 addresses for apps routed that way.
- **Hostnames over WireGuard upstreams.** Hostnames are now resolved with the tunnel's own `DNS =` servers, so `socks5h` clients of a listener work. This also stops DNS-over-HTTPS from logging a failed lookup on every connection through a tunnel with no DNS servers.
- **Diagnostics** shows two new counters: suppressed IPv6 DNS answers and refused flows.

## Under the hood

- **Tailscale core 1.105** (patched fork, rebased on upstream 1.105.0), Go 1.27.3, and the new wireguard-go interfaces.
- **Android:** AGP 9.4, Kotlin 2.4, Gradle 9.8, Compose BOM 2026.09 and current AndroidX libraries. compileSdk is 37; targetSdk stays 36.
- **Releases are built by GitHub Actions** and signed with the Tailmesh release key there, with checksums and signed attestations for every file.
